# 部署、隐私与维护

## 已验证与未验证
本次环境Linux+Python3.13.5；58项后端测试和10个并发自动化HTTP场景通过。离线Chromium渲染/交互通过；浏览器访问本地网址被环境管理策略阻止，未绕过或修改策略。未部署公网，未测试Safari/Windows真机，未接真实模型或行情凭据。

## 本地试用
run.py在项目独立虚拟环境安装依赖，默认127.0.0.1:8017。普通学生应使用受控部署的浏览器入口，不把API密钥发给学生；目前没有任何远端站点。
不要把本地HTTP账户暴露到公网。生产候选部署需要自己拥有的域名、HTTPS反向代理，并设置：
QLAB_HOSTS=你的主机名
QLAB_ORIGIN=https://你的主机名
QLAB_SECURE_COOKIE=1
QLAB_DB=专用私有目录中的数据库路径
再允许服务监听相应受控接口。TLS证书、防火墙和反向代理不由本次交付擅自创建。

## 账户与安全
Argon2密码哈希、服务端8小时会话、HTTPOnly/SameSite=Strict cookie、CSRF令牌、来源/Host检查。每个数据记录按user_id校验，报告导出和删除同样检查。输出转义；上传不执行文件、不访问用户给的来源URL。
没有邮箱验证、邮件找回、管理员控制台、MFA或企业SSO；邮箱只是登录标识。部署者不得替用户查看私人记录而不告知。当前内存限流适用于一个进程，横向扩容前必须换共享限流/生产数据库/任务队列并测试。
请求上限6MB，CSV上限5MB/50k行/50标的。多实例并发、长时压力、漏洞扫描、第三方依赖完整审计和无障碍人工验收尚未完成，不声称生产认证。

## 数据与模型
数据和模型令牌只能放部署环境/.env；禁止Git提交，禁止传浏览器。模型服务需HTTPS，UI逐次征求发送实验摘要同意；不发送邮箱和完整原始数据。对外AI输出未通过事实保证，报告需人工核对。
Tushare daily、Alpha Vantage TIME_SERIES_DAILY为两个不同市场的日线适配，不是私募基金内部接口。权限、频率、费用、保存与再展示范围由实际账户协议决定。缺凭据/上游失败不生成伪成功。
参考官方文档：
https://tushare.pro/document/2?doc_id=27
https://www.alphavantage.co/documentation/
AI接口为chat-completions兼容适配；本次官方DeepSeek文档访问超时，真实兼容性未验收。

## 保存、备份、恢复
var/qlab.db保存本地记录。不要在用户操作时简单复制SQLite数据库文件；使用SQLite backup API，或停止服务后备份完整一致状态。备份包含个人资料，按与数据库相同的权限保护。
每人可导出自身全部记录、重新输入密码删除账户。普通列表最多显示最近200项；个人完整导出不截断。正式产品应增加分页、容量配额和日志保留策略。
课程结束需通知维护人、数据保留期限和停止服务安排。不要把截图中的自动化测试账户计入真实测试人数。
