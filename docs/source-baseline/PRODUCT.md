# Quant Learning Lab · 产品定义

## 已确认范围
- ENT207TC 2026–2027；独立新项目，不复用 ai-workbench 或旧启动包代码。
- 用户：想理解投资方法与风险、无编程经验的大学生。
- 选题：2627S1010 第一子题——中美私募量化基金比较。产品形式：策略比较、风险模拟、AI讲解与学习报告。
- 用户任务：读案例 → 明白指标 → 设置教学实验 → 比较结果与风险 → 问问题 → 保存报告和反思。
- 真实基金案例、教学策略、合成样本严格区分。实验不代表真实基金业绩；不能根据少量样本对国家或基金作普遍优劣结论。

## 完成标准
真实登录与账户隔离；至少5个互通页面；比较、确定性风险模拟、学习/报告三条功能链可用；AI独立连接状态；无凭据不能声称AI已接通。
所有实验可保存、重开和导出。数据来源、用途、时间、币种、费用、未覆盖条件清楚可见。真实测试、外部导师、推广和课堂贡献必须由团队实际完成。

## 不做
实盘下单、支付、公开募资、收益保证、伪造基金收益、伪造访谈、默认公开部署、修改旧项目、全局安装Skill、创建未经请求的云资源。

## 当前环境约束
容器无可用外网DNS，无用户数据/模型API密钥。可完成离线教学样本、真实CSV导入、后端API适配代码、接口故障测试；真实上游API请求与真实私募资料接入待授权验证。
