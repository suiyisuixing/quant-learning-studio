# Quant Learning Lab · 量化学习实验室

**全新独立制作的可运行网站试用版，0.2.0。不是旧项目插件，也不是只有静态页面的启动骨架。**

面向大学生：比较中美资料，用虚拟资金做风险实验，再解释、练习和复盘。

## 先看真实状态

- 已实现：服务端注册/登录/退出、账户隔离、数据导入/来源记录、中美案例录入比较、三方法回测、三因子效果、回撤控制、报告保存/三格式导出、规则讲解、外部AI适配、知识小测进度、反馈与个人数据导出/删除。
- 内置的两份行情均为**合成教学样本**，界面和报告持续标注。没有内置伪造的私募基金业绩或官方背书。
- 真实数据：可导入获授权CSV；Tushare/Alpha Vantage适配已编写，但本次没有真实密钥、网络验收或再分发授权。API适配是未复权日线，必须检查企业行动/可比性。
- AI：未配置时只提供明确标记的规则讲解；填写真实凭据后才可能调用。没有把规则模板冒充AI。真实AI本次未连接。
- 没有部署公网、创建远端仓库、邀请成员或修改任何旧项目。
- 这是可试用的产品候选，不是已经通过真实用户、生产安全、金融模型和数据授权验收的商业正式版。

## macOS启动

解压到新的独立文件夹，在该文件夹的终端运行：

```bash
python3 run.py
```

首次会在**本项目内**创建`.venv`并安装requirements.txt，需联网。不会修改全局依赖。然后打开：

```text
http://127.0.0.1:8017
```

注册自己的学习账户；无需默认管理员密码，不自带测试账户。所有个人记录保存在本项目`var/qlab.db`。停止：终端Ctrl+C。也可运行`zsh start.command`。

Windows：`py -3 run.py`，或双击`start.bat`。需要Python>=3.11；实际验证版本为Linux/Python3.13.5，macOS和Windows实机尚未验证。

已有准备好依赖的独立环境：`python3 run.py --use-current-env`。这里不需要npm、CDN或前端构建；前端是原生ES模块+CSS，后端是FastAPI+SQLite。框架数量不作为质量标准，模块可由团队逐步拆分。

## 第一条可操作流程

1. 注册 → 学习首页，初始知识检查为0，没有假学习进度。
2. 风险模拟 → 选择明确标记的合成样本，保留默认参数或自行设置。
3. 运行三种方法 → 查看真实计算的资金曲线、最大回撤、费用、前后段表现、Rank IC、记录。
4. 学习助手 → 请求规则讲解（明确不是AI）或配置后的真实AI。
5. 写自己的反思 → 保存报告 → 重开/导出Markdown、HTML、完整JSON。
6. 概念小课答题 → 查看解释与真实保存的进度。
7. 退出后重新登录，报告和实验仍在。

## 加入自己的资料

“数据与资料”支持CSV与有来源的中美私募案例。CSV列：

```csv
date,symbol,close,volume,market,currency
2024-01-02,CN-SAMPLE-01,30.0000,10000,CN,CNY
```

以上一行仅为格式示例，不能直接满足历史长度要求。完整自制样本见`examples/`或网站下载按钮。至少45个完整日期、最多50标的/50,000行/5MB。为了不悄悄填充数据，各标的日期必须一致。`CN/CNY`和`US/USD`分别处理。

真实来源以用户声明标记，软件格式检查不能证明其真实性与许可。案例为个人资料，不自动公开给其他账户。不要上传私人账户、企业保密数据或未授权基金净值。

## 连接外部服务

```bash
cp .env.example .env
```

在`.env`填写你被授权使用的密钥。AI为HTTPS chat-completions兼容JSON接口，默认DeepSeek地址；兼容性与费用由部署者实际核验。用户每次请求外部AI必须明确同意发送问题和实验摘要。密钥不发送到浏览器，也不写到报告。

行情和AI未配置或失败会清楚报错；不会把合成数据或规则答案冒充上游结果。
