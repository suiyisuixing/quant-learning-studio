# 建议演示流程（不是已完成的课程视频）

先讲：我们的用户是想理解量化方法和风险的大学生。这里不承诺投资收益。
1. 创建/登录账户，展示首页下一步和初始/真实进度。
2. 中美案例：展示团队实际核实的资料和来源；不足则明确说明，不用虚构基金曲线。
3. 进入模拟，选数据、填写理由，说明真实/合成性质。
4. 运行三种方法，改变一个条件再比较，指出最大回撤与费用。
5. 展开因子效果和时间分段，解释限制，不将历史最优当成未来保证。
6. 请求真实已配置AI或明确的规则讲解；报告中区分两者。AI失败也可查看数字结果。
7. 写下自己的理解，保存报告，退出再登录重开；用一道小测验证理解。
8. 展示实际用户反馈和据此修改，不演示自动化账户作为真人证据。

课堂必须按老师要求完成真实输入—交互—输出。长任务可提前计算但明确告诉评审，不能把预录画面伪装现场。
