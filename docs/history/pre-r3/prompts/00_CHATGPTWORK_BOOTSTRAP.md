# ChatGPT Work Bootstrap 执行规范

来源说明：依据本次用户明确要求、已收到的产品总要求和原始《任务》生成。用户提到的《QuantLab_公开GitHub_完整提示词.md》原件尚未收到，本文件不冒充其原始 bootstrap。

1. 核实 GitHub 身份、写入工具、同名仓库和认可源码。只操作这次新建的 public 仓库，不改旧私有仓库可见性。
2. 使用认可的独立网站源码和框架；缺失则将应用导入/运行标为 BLOCKED，不放入旧项目或 starter。
3. 首次公开推送检查本次所有文件及提交历史，移除密钥、数据库、受限全文/数据、真实用户身份和私人日志。用新仓库的清晰历史记录初始化，不复制无关历史。
4. 保留原始七人分工；保存产品要求、计划、权限说明、七份个人提示词、三份网站 AI 提示词及模板。
5. Yu 是唯一 owner 和最终合并人；成员经核实本人账号后登记，只通过 Fork PR。缺账号不妨碍初始化，登记保持 PENDING，不邀请猜测账号。
6. 先 PLAN-only，owner 记录已批准 PLAN blob 与路径后才能实施。可信范围检查从主分支读政策和代码，未知身份/未批准/超范围默认失败。CODEOWNERS 只作审查。
7. main 要求 PR 与真实检查，禁止强推/删除。仅 owner 具有合并权；不设置 owner 必须批准自己 PR 的死锁。不得自动合并产品 PR。
8. 不包办七人产品，不购买服务、不作未授权付费 API 调用、不部署公网。
9. 实际读取公开仓库、HEAD、保护、CI、任务和文件链接，运行可行的当前检查。报告已完成/未验证/受阻和最小缺口，不能声称缺失源码已上传或旧测试是本次测试。
