# QuantLab软件总提示词：所有成员共同阅读

你正在参与一个独立的学生金融学习网站。先阅读README、原始分工、实际代码和个人任务。只能实施分配给自己的部分；发现本文件覆盖其他人的事项时，提接口需求，不越界包办。

## 1. 产品目标
用简单页面帮助学生理解中美量化投资方法和风险。学生使用虚拟资金、真实获准数据或明确标记的教学样本；通过模拟、比较、论文支持的DeepSeek解释和理解练习逐步学习。不是实盘下单平台，也不是只上传论文聊天的网页。

中美私募案例与自建教学策略分开：案例只能使用真实可核查且允许使用的资料；策略结果必须标明是本系统按指定数据和规则计算。资料不足时展示范围限制，不能用市场指数或股票收益冒充基金真实业绩。

## 2. 不可改变的产品边界
- 保留用户已认可前端；不重新设计全站，不引入另一个旧个人项目。
- 普通用户不需要先配置复杂策略语言或浏览大量K线；提供清楚步骤、解释和可展开的技术详情。
- 不接券商、不处理真实资金、不替学生承诺收益或决定真实交易；没有购买服务/花费额度授权时不进行付费调用。
- DeepSeek只通过后端调用。默认模型ID和支持能力以执行时官方文档、账户实测为准，不凭记忆指定不存在的模型/API。
- RAG不等于训练模型；是否改善回答通过实测证明。不要预写准确率、虚构论文或学生反馈。
- 前端看见的权限与GitHub协作权限不同。学生、资料维护者、审核者的应用权限由服务端独立检查，不因为某人能fork代码就给他生产数据权限。

## 3. 产品能力与完成标准

### F01 账户、首页、继续学习（Zaixuan；Tianqi提供进度接口）
注册/登录/退出、会话处理、输入校验、账户隔离。用户能继续自己的上次练习，不读取其他人的聊天、报告或资料。刷新、重新登录、正常服务重启后已保存内容存在。不得内置通用admin密码。

### F02 案例与数据比较（Xingze内容；Yu计算；Zaixuan界面）
记录案例ID、地区、来源、时间、原文范围、局限和可用数据。并排展示明确可比项；不可比项不给伪精确名次。
市场数据记录来源、抓取/可获得时间、币种、交易日、价格口径、使用限制。固定接口和CSV导入均验证数值/重复/缺失/范围。重试不得重复入库；过期/缺失显式显示，不自动用合成数据顶替。
中美分别按本地市场和币种计算，比较标准化净值或百分比时解释口径；没有汇率数据就不把人民币和美元数额混在一起求和。

### F03 量化、历史模拟、风险和费用（Yu）
先写清算法与输入合同，再实现数据清洗、基准、单指标、多指标教学方法。权重、持仓、现金、调仓和费用规则可追溯。收益、费用、现金与持仓守恒，重复请求有幂等处理。结果不得靠AI计算。
明确数据可获得时间、信号时点和模拟成交规则，后续信息不参与先前决策。说明交易日、复权/分红等处理范围；实际没有实现的现实约束写限制而不是声称全部还原。
结果包括资金变化、收益、最大回撤、费用、调整记录、选定指标的效果或局限。对训练/检验时间与参数选择留记录，比较成本和参数变化，不把同一数据的重复运行算独立市场验证。
同一实验保留dataset/rule/strategy版本、参数、时间和结果摘要；更新参数新建结果，不覆盖原实验。

### F04 论文知识库管理（Zaixuan；Xingze审核；三位成员提供材料）
团队提交资料卡；确认资料可用及相关性后才启用。PDF正文分段保留页码/章节、source_id、version、chunk_id、hash；原文、译文、人工总结、AI摘要各有标签，禁止相互冒充。
公式、表格、扫描页或正文提取不可靠时标记需人工核验，不把乱码入正式索引。首批优先文本型资料，不因追求全格式支持扩大开发。
分离公共获准知识与个人数据。受限论文全文、提取切片、向量索引、私募数据不写入公开Git；公开只能发布被允许的元数据、原创总结和获准样例。
`待审核→可使用→已停用`有真实记录。停用或权限变化须作用于检索、缓存、下载与后续报告访问；不能仅在UI隐藏。旧报告保留可获准的引用身份与撤回提示，不把不再允许展示的全文永久留在可下载产物。
不要自动把新增论文发送到DeepSeek或第三方embedding服务；先核实使用方式和许可。为检索选择简单可验证的起点，再依据失败案例改进；技术论文与金融知识分库/标签隔离。

### F05 检索后DeepSeek回答（Tianqi；Zaixuan提供资料接口）
查询→权限与状态过滤→检索/必要重排→得到有限相关段落→读取经过授权的本次实验摘要→调用DeepSeek→校验引用ID和输出→展示/保存。
不要假设DeepSeek对话API提供文档托管或embedding服务。向量化如采用独立方案，要记录模型、版本、费用与权限，不能默默引入额外云服务。检索模式与配置可复现。
发送最少必要上下文；把资料与用户输入当不可信数据，不执行资料内的指令、不打开任意本机路径、不自动运行模型生成代码。资料链接获取限制协议、域名/地址、重定向、大小和时间，避免任意内网访问。
AI回答包含简明解释、与本次实验关系、来源、适用限制。真实计算数值由后端提供，并通过服务器渲染或校验保持一致。引用只能使用检索允许列表中的真实source/chunk/locator；模型不得自由生成DOI、链接、页码。
证据不足、问题超范围、资料矛盾有明确状态，不硬答。网络超时、限流、额度不足、空输出和格式错误有有限重试/取消和可理解提示；规则讲解不能伪装成真实模型输出。
保存答案、使用的引用身份、知识库/提示词/模型版本和实验ID；敏感内容与公共日志分离。不展示模型的内部思考，仅输出答案和必要的可核验解释。

### F06 学习、进度与报告（Tianqi；Xingze内容；Zaixuan界面）
学习任务从案例/实验产生，检查学生对费用、风险、资料差异和模拟局限的理解；进度依据真实提交，不能以盈利或点击数代表掌握。
学生反思自己填写，AI可给问题和反馈，不替人编个人经历。
报告由已验证实验数字、来源支持的解释和个人记录组成；能保存、重新打开和导出。输出转义不执行HTML/脚本；导出/删除验证账户；重试不产生重复结果。

### F07 真人测试与问题记录（三位资料成员共同；开发者各修自己模块）
先有明确任务和同意，再记录真实操作、系统版本、环境、预期/实际、匿名编号、问题严重性、修复PR和复测。公开只用充分匿名且允许公开的记录，不放联系方式、账号或可识别录屏。
资料/问答测试和真人测试分开统计；不编造测试人数、录音、满意度或改进结果。相同人员重复测试不能伪装成新人。

## 4. 共用接口：先定一个版本，不让模块各算各的
以下为建议契约，Yu组织定稿；字段无法取得时留unknown和原因，不自行补值：
- `ExperimentSummary`：id、owner_id（仅服务端）、market/currency、as_of、dataset_version、strategy/rule版本、参数、results、费用/风险、来源状态、限制。
- `SourceRecord`：source_id、version、标题/作者/年、DOI或原始URL、地区/期间/样本、资料类型、许可/可发送/可展示状态、审核状态和hash。
- `EvidenceChunk`：chunk_id、source_id/version、原文、PDF页码及印刷页/章节位置、提取质量和用途；服务端在授权后返回。
- `RetrievalResult`：query_id、kb_version、retrieval_version、允许引用段落、分数/排序用途说明、未命中或限制原因。
- `AnswerRecord`：answer_id、experiment_id、实际model_id、prompt版本、evidence_ids、答案、状态、限制、运行时间和最小必要用量。
- `LearningAttempt`：user、task、题目版本、真实回答、反馈、完成状态和时间。
- `ReportRecord`：report_id、owner、experiment/answer引用、学习反思、版本和导出状态。
- `FeedbackRecord`：匿名case_id、版本、可复现步骤、实际结果、允许公开状态、问题/复测关联。

资料解析/存储只有Zaixuan的一套；检索选择与回答只有Tianqi的一套；金融数值只取Yu的确定性结果。数据库迁移Zaixuan协调版本，公共启动注册/跨模块schema由Yu合并。不在三个模块重复建立users或reports表。

## 5. 测试与交付
每位开发者对自己模块写单元、接口和负例测试，另外完整跑一次普通浏览器的真实HTTP流程。截图、FastAPI TestClient、静态页面和离线浏览器桥分别标记，不能互相冒充。
必须检查账户隔离、重复点击、输入错误、服务重启、数据失效、论文停用、引用不存在、DeepSeek失败、移动端和桌面可用性。任何受环境限制的测试写明未运行。
RAG对照：同问题、同实验、同模型与可用设置，区分有/无检索；人工核验正确性、引用支持、数值一致、证据不足处理，记录时延和成本。保留开发题与不用于调参的题；评估答案不进检索库；测试结果不预填。
网页部署与代码公开是不同任务。初始化不自动开公网；上线要有owner授权的环境、HTTPS、持久存储、备份恢复、密钥管理和实际URL检查。没有URL就不能声称上线。
每次交付提供：任务/commit、修改文件、实际验证命令和结果、演示步骤、已知限制、下一步依赖。没有证据的能力不能写成完成。
